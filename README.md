## Deskripsi Repositori
Repositori ini merupakan tempat pengumpulan hasil pengerjaan Tugas Pemrograman Dasar TLS 2026[cite: 1] oleh Muhammad Hafidz Ar-Rahman dari kelompok Spinel, mahasiswa Teknik Informatika (TIF) DTETI UGM. Sesuai dengan ketentuan penugasan, penyelesaian dibagi ke dalam dua fase utama:

### 1. Fase 1 (Logika Penyelesaian)
Berisi dokumen PDF yang memuat rancangan logika algoritma dalam bentuk *Pseudocode* beserta penjelasan logikanya secara mendetail untuk dua permasalahan yang diberikan[cite: 1]. 

### 2. Fase 2 (Implementasi C++)
Berisi implementasi *source code* C++ dari rancangan logika yang telah disusun pada Fase 1[cite: 1]. Sesuai batasan aturan, program dibangun murni menggunakan *user-defined function* dan hanya memanfaatkan *library* standar `iostream`[cite: 1].
- `Problem1_TheLastAstronaut.cpp`: Program simulasi untuk mencari urutan eliminasi sirkular dan astronot terakhir yang bertahan dalam misi[cite: 1].
- `Problem2_AlienInTheMiddle.cpp`: Program sistem penyandian huruf rahasia menggunakan logika pergeseran nilai alfabet sesuai posisi karakter sebelumnya[cite: 1].
